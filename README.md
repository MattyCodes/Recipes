# Recipes

A catalogue of things worth making again.

## Index

- [Foods](foods/README.md) — mains, sides, bread, anything you eat with a fork
- [Sauces](sauces/README.md) — sauces, dressings, condiments, spice blends
- [Cocktails](cocktails/README.md) — mixed drinks and the syrups they need
- [Meads](meads/README.md) — honey ferments, batch notes and all

## Adding a recipe

Copy [`TEMPLATE.md`](TEMPLATE.md) into the right directory as `<kebab-case-name>.md`, fill it in,
and add a row to that directory's index. Agents: see [`AGENTS.md`](AGENTS.md).
